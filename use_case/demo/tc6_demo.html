    TC6 · We attacked our own assistant · Nov 2026

    I attacked my own assistant. Before: 13 of 100 runs leaked. After: 0 of 84.

    Service desk staff ask the onboarding assistant about a new hire's ticket. We attacked the shipped path on purpose: local model only, synthetic tickets, a made-up marker in its instructions.

    The limit: one pass, on a 7B open model on a laptop. The pass was re-run on the final code (0709a05) on 2026-11-17: 84 runs on the same local model, and 0 of 84 reached the caller by leaked(). On the final code the input rail is on the request path and stopped the 52 direct runs before the model, so only the 32 tool and indirect runs reached the model, unlike the 2026-11-16 pass. The behaviour scorer flags 1 of 84 (indirect own-ticket, run 7): the reply was withheld, and the scorer matched the app's own withhold notice, not model text. 16 of the 100 before-runs were not repeated after, so the totals differ. No attack was run against the production model.
